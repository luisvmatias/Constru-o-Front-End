# Portal Aurora

Projeto React + Vite criado com estrutura de autenticação e rotas protegidas.

## Como usar

1. Abra a pasta `praticas/projeto-pomodoro/portal-aurora`.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Acesse o endereço exibido pelo Vite.
