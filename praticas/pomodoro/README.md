# Prática Pomodoro - Tela de Login

Projeto de prática desenvolvido dentro da pasta `praticas/pomodoro`.

### Descrição

Tela de login para o projeto Pomodoro com validação de formulário em JavaScript,
layout responsivo e estilo moderno.

### Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Preencha o e-mail e a senha.
3. Clique em `Entrar` para ver a validação do formulário.
